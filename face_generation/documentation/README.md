# FaceGenerator (WGAN-GP)

Программа для генерации человеческих лиц с заданными параметрами на основе датасета **CelebA**. Проект состоит из нейросети (WGAN-GP) и удобного графического интерфейса на **Tkinter**.

## Возможности

С помощью чекбоксов в приложении можно настраивать 7 признаков лица перед генерацией:

* Мужчина / Женщина (`Male`)
* Молодой (`Young`)
* Бледная кожа (`Pale Skin`)
* Лысый (`Bald`)
* Усы (`Mustache`)
* Очки (`Eyeglasses`)
* Улыбка (`Smiling`)
