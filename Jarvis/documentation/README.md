# **Jarvis**



Jarvis is a voice assistant for music control through the Yandex Music API. A light-weighted background utility, built for easy music interaction.



### Description

A lightweight application running in the background. It detects the wake word using the Faster Whisper model, recognizes text based on XLM-RoBERTa, and executes the corresponding request to the Yandex Music API.



### Abilities

1. play track - search for a specific track
2. play artist - search for a specific artist
3. play album - search for a specific album
4. play playlist - search for a specific playlist
5. play wave - play your "wave"
6. play favourite - play favourite playlist
7. play random radio - play random radio from determined
8. track next - play next track
9. track prev - play previous track
10. track pause - pause track
11. track resume - resume track
12. volume up - turn the volume up
13. volume down - turn the volume down
14. set volume - set the exact volume
15. like - like current song
16. dislike - dislike current song
17. ask current track - ask the current playing track
18. other - undefined command
19. exit - exit



### How to start

For now the project is a very early demo version.

To start:

1. Clone this repo
2. Install necessary libraries
3. Start the "App.py" file
